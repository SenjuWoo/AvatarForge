Unity checks and review items
Use the prepared prefab & scene. Conversion creates Blender/FBX files first. Unity preparation builds materials, rig settings, Avatar Descriptor and a preview scene. Copying only the output or dragging model.fbx into Assets skips that setup.
Existing Unity project? Add the included Unity package using Package Manager → Add package from disk, then choose AvatarForge → Import conversion folder and open its Preview scene or Avatar prefab. Keep model.blend outside Unity Assets; Unity can try to launch Blender to import it.
Why does Unity say no animation data?
This is an avatar bind-pose export, without embedded source animation clips. The prepared Humanoid Avatar is driven by VRChat tracking and its default playable layers. Blender constraints, drivers and cloth simulations do not become Unity animation clips. Secondary bones remain available; selected PhysBone roots are configured during Unity preparation.
