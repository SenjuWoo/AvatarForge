# Dependencies and licenses

Pins identify reviewed source revisions; they are not claims that every importer has passed an AvatarForge model conversion. Recorded SHA256 values come from official checksum manifests, GitHub release metadata or hashed official source archives and must be checked against downloaded bytes before extraction.

SourceIO imports must include the original model sidecars and texture tree. Its [native loader](https://github.com/REDxEYE/SourceIO/blob/5.5.4/library/utils/pylib/__init__.py) imports platform-specific `pylib` modules; a Python-only subset is incomplete. Install the complete [5.5.4 release ZIP](https://github.com/REDxEYE/SourceIO/releases/download/5.5.4/SourceIO.zip), whose [release-asset digest](https://api.github.com/repos/REDxEYE/SourceIO/releases/tags/5.5.4) matches the independently downloaded bytes. Source checkouts instead need any recursive submodules present in that revision and a native import check. Do not assume that a generated GitHub source ZIP has the native payload or invent a `sourcepp` revision.

Automatic importer installation uses each catalog entry's exact archive URL, checksum and `archive_subdirectory`, then stages the canonical module folder. Source Tools' official commit ZIP was downloaded and hashed directly. MMD's release ZIP has its module files at archive root; VRM's regular add-on ZIP wraps them in `VRM_Addon_for_Blender-release`. Both release files were downloaded and their SHA256 values matched upstream release-asset digests. Preserve complete importer folders and verify Blender can enable the canonical module after staging.

MMD's official extension includes [OpenCC 0.1.7](https://pypi.org/project/opencc-python-reimplemented/0.1.7/) under Apache-2.0. The worker checks the included pure-Python wheel's SHA256, unpacks it into a temporary process-local folder and retains its bundled license and dictionary files. It does not install Python packages globally. The maintained XPS source archive is staged as `io_xnalara`, with its manifest, contributor credits and source intact. Default core/all installation selects Blender 5.0+; an explicit Blender 4.5 executable override remains available for Collada/native routes. A `.mesh` filename can also identify unrelated game formats such as REDengine; those are not XPS inputs.

Importer licenses cover tool code, not permission to redistribute source models, textures or game assets. AvatarForge processes locally supplied assets and must exclude the user's models from its own Git history and release archives.

The managed reducer's [source](https://github.com/Whinarn/UnityMeshSimplifier/blob/53fdb3122645bcd3ad2c258235200dff3dfbaa9b/Runtime/MeshSimplifier.cs) reads blend-shape frames, interpolates their vertex attributes and writes the frames and bind poses to the reduced mesh. It reads `Mesh.boneWeights`, not the unlimited `BoneWeight1` API, so the influence-count preflight is mandatory before calling `Initialize`. Reduction can still miss a requested polygon budget when preserving skinning or facial deformation requires retaining the original mesh.

AAO's [basic workflow](https://vpm.anatawa12.com/avatar-optimizer/en/docs/tutorial/basic-usage/) removes unused shapes, merges bones and removes unused PhysBones. Configure these operations explicitly for a recipe promising complete skeleton/shape retention. Its [public scripting API contract](https://github.com/anatawa12/AvatarOptimizer#stability-for-scripting-usage) requires supported script-created components to call `Initialize(configurationVersion)` immediately after `AddComponent`. Use NDMF's manual bake to inspect a processed clone and record its actual metrics. AAO's body-hiding shape operation removes selected hidden polygons; it is distinct from general decimation.

## Optional AI bridges

Routine conversion is deterministic; MCP is for inspecting a difficult model or repairing a saved recipe. An installed package, listening port or enabled client entry does not prove that the target editor is connected.

### Blender MCP

[MCP for Blender](https://github.com/ahujasid/mcp-for-blender) is the renamed `blender-mcp` project. Reviewed package 2.1.3 / source `60d2a31b4632a7bc178f3dd636f7e68dfb5c8ae4` is MIT. New installations use `uvx --from mcp-for-blender==2.1.3 mcp-for-blender`; the legacy package is documented upstream. `uvx --from mcp-for-blender==2.1.3 mcp-for-blender install-addon` installs the matching editor addon. Enable it in Blender and start its bridge in the viewport sidebar. The addon auto-starts in interactive Blender, not background mode.

The AI client speaks MCP over stdio to the Python server. The server connects to the addon's loopback TCP endpoint, default `localhost:9876`, configurable through `BLENDER_HOST` / `BLENDER_PORT`. A readiness check should perform MCP `initialize` and `tools/list`, then a read-only scene query through the editor bridge. Keep model inspection separate from the user's active scene by using an isolated Blender process.

### Unity MCP

[MCP for Unity](https://github.com/CoplayDev/unity-mcp) is MIT. Reviewed v10.2.0 / commit `30d22075093d1d35dfb0091c1c7550e9ad948577` declares Unity 2021.3+ and Python 3.10+. Install into the generated project using this pinned UPM URL:

```text
https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#30d22075093d1d35dfb0091c1c7550e9ad948577
```

Open `Window > MCP for Unity`, choose the desired client and connect. [HTTP transport](https://coplaydev.github.io/unity-mcp/architecture/transports) uses `http://localhost:8080/mcp`; the editor connects to the server's WebSocket hub at `/hub/plugin`. Stdio clients use `uvx --from mcpforunityserver==10.2.0 mcp-for-unity --transport stdio`. Match the server and editor package versions.

The server's `/health` checks the Python process. Its [documented source routes](https://github.com/CoplayDev/unity-mcp/blob/v10.2.0/Server/src/main.py) include `/api/instances`, which reports connected editor projects and versions. Complete readiness requires an MCP handshake, tool discovery and a read-only request to the intended project; select its exact `Name@hash` when several editors are open. [Installation guide](https://coplaydev.github.io/unity-mcp/getting-started/install).

For [Ultimate-AI-Starter-Bundle](https://github.com/SenjuWoo/Ultimate-AI-Starter-Bundle) users, reuse its editor bridges when their real handshakes pass. Keep these servers in the model-conversion project/profile; preserve existing personal provider and model configuration.
